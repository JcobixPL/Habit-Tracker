# Habit Tracker

A university full-stack web application for tracking daily habits and monitoring progress over time.

The project was built as part of university coursework and includes both frontend and backend components.

## Features

* user registration and authentication
* creating habits with daily targets
* daily habit check-ins
* habit archiving and restoration
* activity statistics and progress charts
* "Perfect Day" indicator when all active habits are completed

## Tech Stack

### Frontend

* React
* Vite
* JavaScript

### Backend

* Node.js
* Express
* Prisma ORM
* PostgreSQL

### Other

* Docker
* Docker Compose

## Perfect Day

A Perfect Day is a day when all active habits have been completed at 100% of their daily target.

The activity chart visually distinguishes Perfect Days from days when not all habits were completed.

## Running the Project

```bash
docker compose up --build
```
